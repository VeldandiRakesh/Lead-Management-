# LeadFlow CRM

A Full Stack Lead Management System built with React, Node.js, Express and SQLite.

## Tech Stack

- React + Vite
- Tailwind CSS
- Node.js
- Express.js
- SQLite
- JWT Authentication

## Features

- Role-Based Authentication
- Lead Management
- Dashboard
- Search & Filter
- Activity Logs
- CSV/PDF Export

## Installation

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
